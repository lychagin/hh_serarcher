# hh-search

Демон автопоиска вакансий на hh.ru: обходит курируемые листинги, отсеивает по
заголовку, обогащает со страницы вакансии, оценивает ключевыми словами, хранит в
SQLite и публикует отчёты в CSV, Markdown, HTML и Telegram. Python 3.12, uv,
никаких внешних сервисов кроме hh.ru и Bot API.

## Куда смотреть и в каком порядке

1. `docs/superpowers/HANDOFF.md` — где мы сейчас: ветки, ближайший шаг, открытые
   задачи. Читать первым.
2. `docs/superpowers/specs/` — как система устроена. Источник правды об
   архитектуре и решениях, включая замеры с датами.
3. `README.md` — как этим пользоваться владельцу.

Планы в `docs/superpowers/plans/` — исторические документы. Переписывать их не
надо: разошедшийся с кодом план ничего не ломает, а переписанный теряет причину,
по которой решение принималось.

Локальные инварианты, которые ломаются молча, живут рядом с кодом и подгружаются
вместе с ним:

- `hh_search/storage/CLAUDE.md`
- `hh_search/sources/CLAUDE.md`

Этот файл — источник правды о правилах работы, и только о них. Ни одного факта из
спеки он не повторяет: где спека уже утверждает и сторожит, здесь стоит ссылка на
её раздел.

## Ворота

Одна команда, зелёная перед каждым коммитом:

```sh
./gate
```

Она гоняет по порядку и падает на первой красной проверке:

```sh
uv run ruff check .
uv run ruff format --check .
uv run mypy hh_search tests
uv run pytest -q
```

Состав ворот живёт в `gate` и больше нигде: CI зовёт этот же скрипт, а
перечисление выше сверяется с ним тестом. До появления скрипта состав
существовал в `README.md` и `.github/workflows/ci.yml` по отдельности, и класс
отказа «прогнал три из четырёх и сказал зелено» не был перекрыт ничем.

## Внешняя система: hh.ru

- **Только легальный путь.** `robots.txt` соблюдается, блокировки не обходятся.
  RSS запрещён, общий поиск `/search/vacancy` запрещён. Разрешённых форм листинга
  три: голый путь, `?page=N`, `?work_format=…&page=N` — параметр обязан идти
  вместе с `&page=`. При этом `Allow: /vacancies/*?*&page=` разрешает любые
  параметры сознательно: приписать hh.ru запрет, которого он не устанавливал, —
  такая же ошибка, как обойти настоящий.
- **Вежливость.** Честный User-Agent с контактом, пауза 1 с, единицы-десятки
  запросов за прогон. При устойчивом 403 — остановка, а не обход.
- **Факт о поведении hh.ru не считается известным, пока не измерен.** Дата и
  способ проверки обязательны у каждого такого утверждения — особенно там, где на
  нём стоит решение. Сгорели дороже всего остального: спека две сессии
  утверждала, что параметр `area` фильтрует выдачу, целая сессия обсуждала этику
  его применения, а замер показал, что hh.ru игнорирует его вовсе.
- **Новый slug или новая форма запроса — сначала один GET вручную, потом код.**
  На несуществующий slug hh.ru отвечает 200 и общим индексом, а не ошибкой.

## Код

- **Бюджет 150 строк кода на файл** — непустые строки, не комментарий и не
  докстринг. Файл, перешедший границу, **делится**, а не получает
  строку-исключение в §4.3 спеки: решение владельца, принятое трижды.
  Комментарий, объясняющий неочевидное решение, ценнее соблюдения счётчика.
- **Границы слоёв держатся, отступления называются.** Единственное действующее
  отступление названо в §4.3 спеки вместе с его ценой; новое отступление либо
  получает там такую же строку, либо не делается.
- **Штраф вместо отсева** там, где цена ошибки асимметрична. Сгорели: слово
  «курьер» в отсеве убивало «Backend-разработчика курьерской доставки».
- Комментарии, докстринги и сообщения коммитов — по-русски, как весь проект.

## Тесты и сторожа

- **Сторож проверяется интеграционно или не проверяется вовсе.** Сгорели дважды:
  `WorkFormatBlockStats` был создан, покрыт модульным тестом и зелен — но не
  подключён к конвейеру, то есть при дрейфе разметки не сказал бы ни слова, а
  модульный тест этой дыры не видел, потому что звал `.record()` напрямую. И тест
  утечки токена был зелен вакуумно: он гонял `ConnectError`, а httpx пишет URL в
  свою строку только после успешного ответа.
- **Все Critical в этом проекте нашлись исполнением, ни один — чтением кода.**
  Ревьюеру предписывать атаковать модуль своими входами, а не читать дифф.
- **Утверждение документа, которое дёшево сверить исполнением, обязано сверяться
  тестом.** Абзац «сверить спеку с кодом» в чеклисте не работает по построению: он
  выполняется один раз, а расходятся они каждый раунд. Сгорели на
  закономерности: с кодом разошлись ровно те разделы спеки, которых не сторожил
  ни один тест, а все сторожимые оказались безупречными — документ без
  сторожащего теста протухает. Живые сторожа документов —
  `tests/test_spec_matches_code.py`, `tests/test_config_example.py`,
  `tests/test_claude_md.py`. Покраснел такой тест — правьте документ вместе с
  кодом, а не выключайте сторожа.
- **Число, обязанное протухать, в документ не пишется.** Ни счётчика тестов, ни
  таблицы строк по файлам: сторожится список, а не число.
- **Живая фикстура — условие необходимое, но не достаточное.** Сгорели: фикстура
  листинга, снятая с московского выхода, скрыла редирект на региональный
  поддомен.
- Контрактные тесты ходят в живой hh.ru, в ворота не входят и в CI отсеиваются
  меткой `network`. Вручную — `uv run pytest -m network`.
- Мутационный харнесс врёт дважды, и оба раза лечатся окружением: `NO_COLOR=1`
  против ANSI-кодов pytest в подпроцессе, `PYTHONDONTWRITEBYTECODE=1` плюс чистка
  `__pycache__` против кэша байткода при мутации, не меняющей размер файла.

## Процесс

- Работа идёт спека → план → задачи. Ветка на тему, `main` напрямую не правится.
- **Находки ревью чинятся автоматически:** Critical и Important — в fix-loop с
  дифференциальной проверкой каждого теста, Minor — в ledger. К владельцу
  обращаться только если починка меняет решение, принятое на брейншторме, либо
  варианты равноценны.
- `docs/superpowers/HANDOFF.md` обновляется в конце сессии: состояние, ветки,
  ближайший шаг, открытые задачи. Правила туда не возвращаются — их место здесь.

## Секреты и данные

- `.env` содержит живой токен Telegram. Не выводить в лог, не печатать в вывод
  команд, не коммитить. Фильтр секрета в логах есть и покрыт тестом — это не
  повод проверять его вручную живым токеном.
- `data/` — рабочий том: SQLite, отчёты, логи. Под `.gitignore`, в образ не
  копируется.
