# CLAUDE.md и единая команда ворот — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перенести правила работы из документа состояния в постоянно загружаемый `CLAUDE.md`, доставить локальные инварианты в два подкаталога и свести состав ворот к одному скрипту.

**Architecture:** Корневой `CLAUDE.md` несёт только правила и не повторяет ни одного факта из спеки. Два вложенных `CLAUDE.md` несут инварианты, которые ломаются молча. Состав ворот переезжает в исполняемый скрипт `gate`, который зовёт CI. Все четыре утверждения, дешёвые к сверке исполнением, получают сторожа в `tests/test_claude_md.py`.

**Tech Stack:** Python 3.12, pytest, PyYAML (уже в зависимостях), POSIX sh. Новых зависимостей проект не получает.

**Спека:** `docs/superpowers/specs/2026-07-30-claude-md-design.md`. При расхождении плана и спеки верна спека.

**Одно уточнение спеки, сделанное планом.** §2 перечисляет восемь разделов корневого документа, а §6.4 требует, чтобы корневой документ перечислял вложенные файлы, — но места для этого перечня §2 не называет. План кладёт перечень в раздел 2 «Куда смотреть»: это навигация, и отдельного девятого раздела она не заслуживает. Перечень появляется в Task 3 вместе с самими файлами, иначе сторож путей (§6.1) покраснеет на ссылке в несозданное.

## Global Constraints

- Ворота, зелёные после КАЖДОГО коммита: `./gate` (после Task 1; до него — четыре команды из `.github/workflows/ci.yml`).
- Состав ворот — ровно тот, что в CI: `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy hh_search tests`, `uv run pytest -q`. Форма `mypy --strict` встречается в старых планах — она неверна как команда: `strict = true` живёт в `pyproject.toml`, а сторож §6.2 сверяет документ со скриптом буквально.
- `line-length = 100`, `target-version = py312`. Новых зависимостей нет.
- Новый код обязан проходить `mypy` в strict-режиме: у каждого теста `-> None`, у каждого хелпера — аннотированный возврат.
- Тесты не ходят в сеть. Ни один тест этого плана сети не касается.
- Комментарии, докстринги и сообщения коммитов — по-русски.
- Бюджет 150 строк кода на файл. `tests/test_claude_md.py` в него укладывается и строки-исключения в §4.3 спеки не требует.
- **§4.3 спеки не правится.** `test_spec_module_tree_matches_the_package` считает инвентарь по расширениям `.py` и `.sql` — файлы `.md` внутри пакета в него не попадают. Проверено чтением реализации.
- Ветка: `region-work-format`, поверх коммита спеки `e2149d9`.
- Каждый сторож этого плана проверяется мутацией: порча документа обязана красить ровно один тест. Шаг проверки включён в каждую задачу и не пропускается.

- [ ] **Step 1: Написать падающий сторож «CI зовёт gate и только его»**

Создать `tests/test_claude_md.py`:

```python
"""Сторожа CLAUDE.md и единой команды ворот.

Правило проекта «документ без сторожащего теста протухает» применяется и к
самому CLAUDE.md. Здесь живут сторожа его утверждений — тех, которые дёшево
сверить исполнением: пути существуют, состав ворот совпадает со скриптом, CI
зовёт скрипт и только его, корневой документ знает все вложенные.

Каждый сторож проверен мутацией: порча утверждения красит ровно один тест.
"""

import re
from pathlib import Path

import yaml

ROOT = Path(__file__).resolve().parent.parent
GATE = ROOT / "gate"
CI = ROOT / ".github/workflows/ci.yml"


def _ci_run_steps() -> list[str]:
    """Тело каждого `run`-шага джобы CI."""
    workflow = yaml.safe_load(CI.read_text(encoding="utf-8"))
    steps = workflow["jobs"]["check"]["steps"]
    return [step["run"] for step in steps if "run" in step]


def test_ci_runs_the_gate_and_no_check_beside_it() -> None:
    """CI обязан звать `./gate` и не звать проверки напрямую.

    Второе условие — то, что делает этот тест сторожем, а не украшением:
    без него четвёртую проверку можно вернуть в CI мимо `gate`, и состав
    ворот снова начнёт существовать в двух местах. Шаги подготовки
    (`uv python install`, `uv sync`) проверками не являются и под запрет не
    попадают.
    """
    runs = _ci_run_steps()
    assert "./gate" in runs, f"CI не зовёт ./gate: {runs}"
    direct = [run for run in runs if re.search(r"\b(ruff|mypy|pytest)\b", run)]
    assert direct == [], f"проверка в CI идёт мимо ./gate: {direct}"
```

- [ ] **Step 1: Написать два падающих сторожа**

Дописать в `tests/test_claude_md.py` после `_ci_run_steps`:

```python
# Расширения, по которым токен без слэша всё равно опознаётся как путь.
# `.txt` здесь нет намеренно: `robots.txt` упоминается как имя файла на
# стороне hh.ru, а не как файл репозитория.
PATH_SUFFIXES = (".md", ".py", ".yaml", ".yml", ".sql", ".toml")

# Пути, которых нет в свежем клоне: рабочий том и локальный .env оба под
# .gitignore. Упомянуть их в CLAUDE.md нужно, а проверить существованием
# нельзя — в CI проверка бы краснела на чистом checkout.
RUNTIME_ONLY = frozenset({"data", ".env"})


def _uv_commands(text: str) -> list[str]:
    """Строки, начинающиеся с `uv run`, в порядке появления."""
    return [line.strip() for line in text.splitlines() if line.strip().startswith("uv run ")]


def _section(path: Path, heading: str) -> str:
    """Текст раздела от заголовка до следующего заголовка того же уровня."""
    text = path.read_text(encoding="utf-8")
    rest = text[text.index(heading) + len(heading) :]
    level = heading.split(" ")[0]
    end = rest.find(f"\n{level} ")
    return rest if end == -1 else rest[:end]


def _claude_md_files() -> list[Path]:
    """Корневой CLAUDE.md и все вложенные внутри пакета."""
    return [ROOT / "CLAUDE.md", *sorted((ROOT / "hh_search").rglob("CLAUDE.md"))]


def _looks_like_a_path(token: str) -> bool:
    """Токен в обратных кавычках, который обязан существовать на диске.

    Отброшено всё, что путём быть не может: URL-пути hh.ru (начинаются с
    `/`), шаблоны и команды (содержат `?`, `{`, `*` или пробел). Из остатка
    путём считается токен со слэшем или с известным расширением.

    Токены без слэша и без расширения (`time_utils`, `gate`,
    `WorkFormatBlockStats`) проверка пропускает сознательно: отличить имя
    модуля от имени класса регуляркой нечем, а требовать расширения у
    каждого упоминания значило бы портить текст ради сторожа. Дыра названа
    в спеке §6.1 — опечатка в `time_utils` поймана не будет.

    Голое расширение (`.py`, `.md`) — не путь, а упоминание расширения:
    правила проекта говорят про файлы `.py` и `.sql`, и без этой отсечки
    сторож требовал бы, чтобы в корне лежал файл с именем `.py`.
    """
    if token.startswith("/") or any(char in token for char in "?{* "):
        return False
    if token.rstrip("/") in RUNTIME_ONLY or token in PATH_SUFFIXES:
        return False
    return "/" in token or token.endswith(PATH_SUFFIXES)


def test_every_path_in_claude_md_exists() -> None:
    """Путь из CLAUDE.md обязан существовать — от корня или от своего каталога.

    Два способа разрешения нужны оба: во вложенном документе естественно
    писать `base.py` про сосед по каталогу и `hh_search/pipeline/enrichment.py`
    про чужой пакет. Ловит переезды файлов и опечатки в ссылках.
    """
    missing: list[str] = []
    for doc in _claude_md_files():
        for token in re.findall(r"`([^`\n]+)`", doc.read_text(encoding="utf-8")):
            if not _looks_like_a_path(token):
                continue
            candidate = token.rstrip("/")
            if (ROOT / candidate).exists() or (doc.parent / candidate).exists():
                continue
            missing.append(f"{doc.relative_to(ROOT)}: {token}")
    assert missing == [], f"путь из CLAUDE.md не найден: {missing}"


def test_claude_md_gate_section_matches_the_gate_script() -> None:
    """Перечень проверок в §Ворота — копия скрипта, а копии обязаны сверяться.

    Перечень в документе нужен: в fix-loop гоняют одну проверку отдельно, и
    её надо знать. Но именно копия и протухает первой, поэтому сверяется
    буквально, включая порядок.
    """
    documented = _uv_commands(_section(ROOT / "CLAUDE.md", "## Ворота"))
    assert documented == _uv_commands(GATE.read_text(encoding="utf-8"))
```

## Ворота

Одна команда, зелёная перед каждым коммитом:

```sh
./gate
```

Она гоняет по порядку и падает на первой красной проверке:

```sh
uv run ruff check .
uv run ruff format --check .
uv run mypy hh_search tests
uv run pytest -q
```

Состав ворот живёт в `gate` и больше нигде: CI зовёт этот же скрипт, а

## Внешняя система: hh.ru

- **Только легальный путь.** `robots.txt` соблюдается, блокировки не обходятся.
  RSS запрещён, общий поиск `/search/vacancy` запрещён. Разрешённых форм листинга
  три: голый путь, `?page=N`, `?work_format=…&page=N` — параметр обязан идти
  вместе с `&page=`. При этом `Allow: /vacancies/*?*&page=` разрешает любые
  параметры сознательно: приписать hh.ru запрет, которого он не устанавливал, —
  такая же ошибка, как обойти настоящий.
- **Вежливость.** Честный User-Agent с контактом, пауза 1 с, единицы-десятки
  запросов за прогон. При устойчивом 403 — остановка, а не обход.
- **Факт о поведении hh.ru не считается известным, пока не измерен.** Дата и
  способ проверки обязательны у каждого такого утверждения — особенно там, где на
  нём стоит решение. Сгорели дороже всего остального: спека две сессии
  утверждала, что параметр `area` фильтрует выдачу, целая сессия обсуждала этику
  его применения, а замер показал, что hh.ru игнорирует его вовсе.
- **Новый slug или новая форма запроса — сначала один GET вручную, потом код.**
  На несуществующий slug hh.ru отвечает 200 и общим индексом, а не ошибкой.

## Код

- **Бюджет 150 строк кода на файл** — непустые строки, не комментарий и не
  докстринг. Файл, перешедший границу, **делится**, а не получает

## Тесты и сторожа

- **Сторож проверяется интеграционно или не проверяется вовсе.** Сгорели дважды:
  `WorkFormatBlockStats` был создан, покрыт модульным тестом и зелен — но не
  подключён к конвейеру, то есть при дрейфе разметки не сказал бы ни слова, а
  модульный тест этой дыры не видел, потому что звал `.record()` напрямую. И тест
  утечки токена был зелен вакуумно: он гонял `ConnectError`, а httpx пишет URL в
  свою строку только после успешного ответа.
- **Все Critical в этом проекте нашлись исполнением, ни один — чтением кода.**
  Ревьюеру предписывать атаковать модуль своими входами, а не читать дифф.
- **Утверждение документа, которое дёшево сверить исполнением, обязано сверяться
  тестом.** Абзац «сверить спеку с кодом» в чеклисте не работает по построению: он
  выполняется один раз, а расходятся они каждый раунд. Живые сторожа документов —
  `tests/test_spec_matches_code.py`, `tests/test_config_example.py`,
  `tests/test_claude_md.py`. Покраснел такой тест — правьте документ вместе с
  кодом, а не выключайте сторожа.
- **Число, обязанное протухать, в документ не пишется.** Ни счётчика тестов, ни
  таблицы строк по файлам: сторожится список, а не число.
- **Живая фикстура — условие необходимое, но не достаточное.** Сгорели: фикстура
  листинга, снятая с московского выхода, скрыла редирект на региональный
  поддомен.
- Контрактные тесты ходят в живой hh.ru, в ворота не входят и в CI отсеиваются
  меткой `network`. Вручную — `uv run pytest -m network`.
- Мутационный харнесс врёт дважды, и оба раза лечатся окружением: `NO_COLOR=1`
  против ANSI-кодов pytest в подпроцессе, `PYTHONDONTWRITEBYTECODE=1` плюс чистка
  `__pycache__` против кэша байткода при мутации, не меняющей размер файла.
